# DomainEnglish（体験版）

AIへの指示（プロンプト）に使う英語を、ゲーム感覚で学ぶ日本人向けの学習アプリです。

## 中身
- `index.html` … アプリ本体（これだけで動きます）
- `favicon.svg` … ブラウザのタブに出るアイコン
- `vercel.json` … Vercel用の設定（安全のための基本設定）

## 公開のしかた
1. GitHubでリポジトリを作り、4つのファイルをアップロードする
2. Vercelで「Add New → Project」から、そのリポジトリを「Import」→「Deploy」

## 更新のしかた
GitHubで「Add file → Upload files」から同じ名前のファイルを上書きすると、Vercelが自動で更新します。

## データについて
- 学習記録は、使っている人のブラウザの中だけに保存されます（サーバーには送りません）
- 外部のAIサービスやデータベースは使っていません

## 改善のしかた
アプリの「きろく」画面で「改善レポートをコピー」を押し、その内容をもとに次の改善を決めます。
